# 华为2024届校园招聘·硬件开发工程师 第1-5套考点分析

> 题目来源：硬件开发/设计工程师、硬件通用/单板开发  
> 题型：单选题、多选题、判断题

---

## 一、整体考点方向概述

五套题目涵盖**模拟电路、数字电路、电源设计、信号完整性/EMC、元器件选型与特性、PCB设计、通信接口协议、测量仪器仪表、控制系统**等核心硬件方向。考点分布广泛但重点突出，高频考点集中在：

- **元器件特性**（电容、电感、二极管、MOSFET/BJT）
- **信号完整性**（反射、匹配、抖动、边沿质量）
- **电源设计**（BUCK、LDO、开关电源、变压器、保护电路）
- **数字逻辑与接口**（GPIO、I²C、计数器、逻辑电平）
- **EMC/EMI**（PCB布局布线、防护器件）

### 📌 3. 信号完整性（SI）

| 考点细项 | 涉及套数 | 具体题目关键词 |
|---------|---------|--------------|
| 信号反射 | 1、3、4套 | 阻抗不连续→反射；终端匹配(RL=Z0)无反射；开路反射系数=1，短路=-1 |
| 反射引起原因 | 1套 | 不同层阻抗不一、跨平面分割、过孔、线宽变化 |
| 传输线 | 4、5套 | 微带线/带状线/共面波导/同轴线；相同板材微带线传播速度比带状线快；RLGC等效 |
| 阻抗匹配方式 | 2、5套 | 串联电阻匹配、AC交流匹配、并联端接、Thevenin端接；始端匹配计算（Rmatch = Z0 - Rs） |
| 信号边沿不单调影响 | 2、3、4套 | 产生错误采样、降低时序容限（主要问题）；可能影响EMC和器件寿命（次要） |
| 建立时间tSU | 1套 | 数据在时钟有效沿到来前必须稳定的时间 |
| 抖动（Jitter） | 1、3套 | 地弹、热噪声、辐射、串扰均可引起；抖动不是匹配问题 |
| 回沟信号 | 1套 | 非末端测试、走线拓扑不好、连接器阻抗不连续 |
| SI基本概念 | 1套 | 集总电路/分布式系统/信号完整性/特征阻抗 |
| 互连线损耗因素 | 2、4套 | 介电常数、线长、频率（主要），环境温度（次要） |
| 行波时钟/行波计数器 | 4、5套 | 将分频时钟驱动其他寄存器=行波时钟；行波计数器实现简单但不推荐使用 |
| 电感/电容突变特性 | 5套 | 电感的**电流**不能突变；电容的**电压**不能突变 |
| 噪声容限 | 3套 | TTL/CMOS电路中：Vohmin-Vihmin ≥ 0.4V，Vilmax-Volmax ≥ 0.4V |

| 存储器类型 | 3套 | PROM=可编程只读存储器 |

## 四、易错考点提示

| 易错点 | 正确结论 |
|-------|---------|
| 磁珠是储能元件 | ❌ 磁珠是**耗能**元件，非储能 |
| 温度降低时电解电容ESR减小 | ❌ 温度降低→ESR**增大**，容量减小 |
| 钽电容抗浪涌能力强，应放在铝电解前 | ❌ 钽电容抗浪涌能力**弱**，应放在铝电解**后** |
| 锁相环锁定后稳态相差为零 | ❌ 锁定后相差是**固定值**，不一定为零 |
| 总线传送控制分为同步和异步两种 | ❌ 有四种：同步、异步、半同步、分离 |
| 晶振负载电容越大驱动能力越强 | ❌ 负载电容影响频率，与驱动能力无直接正相关 |
