# 模拟电路知识点详解 —— 电容特性

---

## 一、理想电容的基本特性

### 1. 电容的定义

电容是衡量导体储存电荷能力的物理量。两个相互绝缘的导体之间，加上电压V后储存电荷Q，电容定义为：

$$C = \frac{Q}{V}$$

单位：法拉(F)。1F = 1库仑/伏特。实际中常用 pF(10^-12)、nF(10^-9)、uF(10^-6)。

### 2. 平行板电容器

最基本的电容模型是平行板电容器：

$$C = \frac{\varepsilon_0 \cdot \varepsilon_r \cdot A}{d}$$

其中：
- $\varepsilon_0$ = $8.854 \times 10^{-12}$ F/m（真空介电常数）
- $\varepsilon_r$ = 介质的相对介电常数（也叫Dk）
- $A$ = 极板面积
- $d$ = 极板间距

**关键推论**：
- 面积A越大 → C越大
- 间距d越小 → C越大
- 介电常数Dk越大 → C越大

这个公式在PCB电源平面设计中也有直接应用——电源层和地层之间就是一个平行板电容器，层间距越小、面积越大、Dk越高，则平面间电容越大，有利于PDN去耦。

### 3. 电容的电压-电流关系

电容上的电流与电压变化率成正比：

$$i(t) = C \cdot \frac{dv(t)}{dt}$$

**推论**：
- 电压不变(直流) → dv/dt = 0 → i = 0，即电容"隔直"
- 电压变化越快(高频) → dv/dt越大 → i越大，即电容"通交"
- 这就是电容"隔直通交"的物理本质

反过来，电压是电流的积分：

$$v(t) = \frac{1}{C} \int i(t)\,dt + V_0$$

这说明电容两端电压不能突变（需要无穷大电流），这是电容在电源滤波中能"稳压"的根本原因。

### 4. 电容的阻抗（容抗）

在正弦交流信号下，电容的阻抗为纯虚数：

$$Z_c = \frac{1}{j \cdot 2\pi f C}$$

取模得到容抗：

$$X_c = \frac{1}{2\pi f C}$$

**推导过程**：
设正弦电压 $v(t) = V_m \sin(2\pi f t)$，则：

$$i(t) = C \cdot \frac{dv}{dt} = C \cdot V_m \cdot 2\pi f \cdot \cos(2\pi f t)$$

电流幅值 $I_m = C \cdot V_m \cdot 2\pi f$，因此：

$$X_c = \frac{V_m}{I_m} = \frac{1}{2\pi f C}$$

**关键推论**：
- 频率f越高 → Xc越小 → 电容对高频信号阻抗越低（更容易通过）
- 容值C越大 → Xc越小 → 同频率下阻抗更低
- 这就是华为考题中"频率越高、容值越大→阻抗越小"的数学依据

## 二、非理想电容的等效模型

### 1. 为什么需要非理想模型？

理想电容假设：无损耗、无寄生电感、无寄生电阻。但实际电容器存在：
- 引脚和内部电极有电阻 → ESR（等效串联电阻）
- 引脚和内部结构有电感 → ESL（等效串联电感）
- 介质有漏电 → 并联电阻（通常忽略）

### 2. 串联等效模型

实际电容的标准等效模型是三者**串联**：

$$Z_{total} = ESR + j \cdot 2\pi f \cdot ESL + \frac{1}{j \cdot 2\pi f \cdot C}$$

即：

$$Z = R + j\left(\omega L - \frac{1}{\omega C}\right)$$

其中 $\omega = 2\pi f$。

这个模型用文字描述就是：

```
[ESL(电感)] ---串联--- [ESR(电阻)] ---串联--- [C(电容)]
```

**为什么是串联而非并联？**

物理上看，电流进入电容器时：
1. 先经过引脚/引线 → 贡献ESL和部分ESR
2. 再经过内部电极 → 贡献部分ESR
3. 最后经过介质储能 → 这才是理想C的部分

电流是**依次**流过这三个部分的，所以是串联关系。这就是考题中"非理想电容等效模型是C+L+R串联"的物理解释。

### 3. 阻抗-频率曲线分析

把上面的阻抗表达式按频率分析：

**低频段**（$f$ 很小）：

容抗 $X_c = \frac{1}{\omega C}$ 很大，远大于 $\omega L$ 和 $ESR$，$Z \approx \frac{1}{\omega C}$，呈容性，阻抗随频率升高而减小（斜率 $-20\text{dB/decade}$）

**谐振点**（$f = f_{SRF}$，自谐振频率）：

$$\omega L = \frac{1}{\omega C} \quad \Rightarrow \quad (2\pi f)^2 \cdot L \cdot C = 1$$

解得：

$$f_{SRF} = \frac{1}{2\pi\sqrt{LC}}$$

此时感抗和容抗互相抵消：$Z = ESR$（纯电阻，阻抗最小值）

**高频段**（$f > f_{SRF}$）：

感抗 $\omega L$ 远大于 $\frac{1}{\omega C}$ 和 $ESR$，$Z \approx \omega L = 2\pi f \cdot ESL$，呈感性，阻抗随频率升高而增大（斜率 $+20\text{dB/decade}$）

**整条曲线形状**：一个"V"形（对数坐标下），最低点在SRF处。

```
阻抗 |
     | \              /
     |  \            /  ← 感性区(ESL主导)
     |   \          /
     |    \   ESR  /
     |     \__|___/
     |        SRF
     |  容性区           
     |  (C主导)          频率 →
```

### 4. SRF（自谐振频率）的影响因素

$$f_{SRF} = \frac{1}{2\pi\sqrt{ESL \cdot C}}$$

由此推出：
- **容值C越小 → SRF越高**（分母变小）
- **ESL越小 → SRF越高**（分母变小）
- 同封装(ESL相同)下，10pF的SRF远高于10uF
- 同容值下，封装越小(如0402 vs 0805) → ESL越小 → SRF越高

这就是考题"同为0805封装，10pF的SRF最高"的数学推导依据。

### 5. 工程意义

电容只有工作在SRF**以下**的频率才表现为"电容"（去耦/滤波有效）。超过SRF后表现为"电感"，反而会阻碍高频信号。

所以：
- **滤波电容**的SRF必须高于目标滤波频率
- **隔直电容**的SRF必须高于信号频率（确保在信号频率下呈低阻容性）
- 实际设计中用**多个不同容值的电容并联**，覆盖宽频率范围

## 三、DC偏置效应

### 1. 现象描述

陶瓷电容（特别是II类介质 X5R/X7R/Y5V）在施加直流偏置电压后，有效容值会**下降**。

### 2. 物理机制

陶瓷电容使用高介电常数的钛酸钡(BaTiO3)等铁电材料。这些材料的介电常数 $\varepsilon_r$ 不是常数，而是随外加电场强度变化的：

$$\varepsilon_r = \varepsilon_r(E)$$

其中 $E = \frac{V}{d}$（电场强度 = 电压 / 极板间距）。

在无偏置时，钛酸钡的电畴随机排列，宏观极化率最大，$\varepsilon_r$ 达到最大值。

施加DC偏置后：
1. 电畴被部分定向排列（极化饱和趋势）
2. 剩余可极化的电畴数量减少
3. 对交流小信号的响应（即有效 $\varepsilon_r$）降低

回到平行板公式：

$$C = \frac{\varepsilon_0 \cdot \varepsilon_r(V_{dc}) \cdot A}{d}$$

$\varepsilon_r(V_{dc}) < \varepsilon_r(0)$，所以：

$$C_{\text{有偏置}} < C_{\text{无偏置}}$$

### 3. 量化影响

典型数据（以0805/10uF/X5R/6.3V为例）：
- 0V偏置：10uF（标称值）
- 3.3V偏置：约6~7uF（衰减30-40%）
- 5V偏置：约4~5uF（衰减50-60%）

容值衰减与偏置电压/额定电压的比值大致成正相关。这就是为什么工程中电容需要**降额使用**——不仅是电压可靠性，还因为容值会衰减。

### 4. I类 vs II类介质

- **I类(C0G/NP0)**：介电常数低但稳定，DC偏置几乎不影响容值。适合精密电路。
- **II类(X5R/X7R/Y5V)**：介电常数高但不稳定，DC偏置、温度都会显著影响容值。适合滤波/去耦。

## 四、温度对电容的影响

### 1. 陶瓷电容

不同介质等级的温度特性：
- **C0G(NP0)**：-55~+125度C范围内容值变化 +-30ppm/度C（极稳定）
- **X5R**：-55~+85度C范围内容值变化 +-15%
- **X7R**：-55~+125度C范围内容值变化 +-15%
- **Y5V**：-30~+85度C范围内容值变化 +22%/-82%（极不稳定）

### 2. 电解电容

铝电解电容在低温下：
- 电解液电导率下降 → ESR**增大**
- 有效容值**减小**
- 损耗角增大

推导过程：电解液的电导率 $\sigma$ 与温度的关系近似为：

$$\sigma(T) = \sigma_0 \cdot e^{-\frac{E_a}{kT}}$$

$T$ 降低 → $e$ 指数项减小 → $\sigma$ 减小 → 电解液阻抗增大 → ESR增大。

同时，低温下电解液介电性能下降，有效介电常数减小，导致容值减小。

这就是考题"铝电解ESR随温度降低而增加"和"电解电容低温下容值变小"的物理本质。

## 五、电容的损耗与品质因数

### 1. 损耗角正切 (tan delta / DF)

$$\tan(\delta) = \frac{ESR}{X_c} = ESR \cdot 2\pi f C$$

也叫做介质损耗因数(DF, Dissipation Factor)。

物理意义：每个充放电周期中，以热量形式损耗的能量与存储能量之比。

### 2. 品质因数 Q

$$Q = \frac{1}{\tan(\delta)} = \frac{X_c}{ESR} = \frac{1}{ESR \cdot 2\pi f C}$$

Q越高说明电容损耗越小，品质越好。

### 3. ESR的功率损耗

通过电容的纹波电流Irms导致ESR发热：

$$P_{ESR} = I_{rms}^2 \cdot ESR$$

这在开关电源滤波中非常重要——大纹波电流+高ESR = 电容过热失效。所以Buck电源输出用低ESR陶瓷电容，而非高ESR的电解电容。

## 六、电容在电路中的核心应用

### 1. 滤波/去耦

原理：电容对交流呈低阻抗，将噪声电流旁路到地。

设计要点：
- 去耦电容必须**靠近**IC电源引脚
- 多个不同容值电容并联覆盖宽频段
- 关注SRF、ESR、ESL、DC偏置容值衰减、温度衰减（全部，对应考题"ABCD全选"）

### 2. 隔直(AC耦合)

原理：电容通交隔直，只允许交流信号通过，阻止直流偏置传递。

设计要点：
- 隔直电容的SRF必须**大于**信号频率，确保在信号频段呈容性（低阻）
- 容值要足够大，使得在信号最低频率处的容抗远小于负载阻抗：
$$X_c = \frac{1}{2\pi f_{min} C} \ll R_{load}$$

通常要求 $X_c < \frac{R_{load}}{10}$

### 3. 谐振(LC电路)

串联谐振：

$$f_0 = \frac{1}{2\pi\sqrt{LC}}$$

谐振时阻抗最小 → $Z = ESR \approx 0$（理想情况）

并联谐振：同样频率公式，谐振时阻抗最大 → $Z \to \infty$（理想情况）

### 4. 定时/RC充放电

$$v(t) = V_0 \left(1 - e^{-\frac{t}{RC}}\right) \quad \text{（充电）}$$

$$v(t) = V_0 \cdot e^{-\frac{t}{RC}} \quad \text{（放电）}$$

时间常数 $\tau = RC$，充电到63.2%需要1个 $\tau$，充电到99.3%需要5个 $\tau$。

## 七、陶瓷电容的失效模式

### 1. 主要失效模式

- **短路**（最常见、最危险）：介质层裂纹/导电颗粒污染 → 层间短路
- **开路**：焊接断裂/内部电极断裂

陶瓷电容失效模式以**短路为主**，这与电解电容不同（电解电容常见漏液、干涸 → 开路）。

### 2. 导致短路的原因

- 机械应力：弯曲/振动导致陶瓷体裂纹
- 电压过高：介质击穿
- 银迁移：高湿度+电场 → 银离子迁移 → 层间导通
- 制造缺陷：介质中混入导电颗粒

## 八、电容选型工程要点总结

| 参数 | 影响 | 设计对策 |
|------|------|----------|
| 容值 | 决定滤波频率下限 | 根据目标频率和阻抗要求选择 |
| ESR | 影响损耗和纹波 | 开关电源选低ESR；LDO注意ESR范围 |
| ESL | 影响高频性能 | 选小封装降低ESL |
| SRF | 决定有效工作频率上限 | SRF>目标频率 |
| DC偏置 | 容值衰减 | 查阅厂商曲线,必要时选更大额定电压 |
| 温度 | 容值和ESR变化 | 选合适温度等级(X7R优于Y5V) |
| 额定电压 | 可靠性 | 降额使用(一般用到额定的50-80%) |

## 附录：等效模型的物理本质——寄生参数详解

### A1. 什么是"寄生"？

"寄生"(parasitic)的意思是**不期望存在但物理上无法避免**的效应。你买了一个"电容"，你只想要它储存电荷，但由于它是用真实的材料、真实的几何结构制造出来的，它天然就会**附带**一些电阻特性和电感特性。这些不是你设计的，而是"寄生"出来的。

### A2. 寄生电阻(ESR)的物理来源

ESR = Equivalent Series Resistance，等效串联电阻。

一个真实的电容器，电流从一个引脚进入，经过内部结构，从另一个引脚流出。这条电流路径上的**每一段导体都有电阻**：

```
外部引脚(金属丝/焊盘)
  ↓ ← 这段金属有电阻
内部引线(连接引脚到电极的导体)
  ↓ ← 这段导体有电阻
内部电极(金属箔或金属化膜层)
  ↓ ← 金属箔本身有电阻（特别薄的箔电阻不小）
介质层(陶瓷/电解液/薄膜)
  ↓ ← 介质的极化过程有损耗，等效为一个电阻
内部电极(另一片)
  ↓
内部引线
  ↓
外部引脚
```

ESR由两部分组成：

**第一部分：导体电阻（欧姆损耗）**

金属导体的电阻公式：$R = \frac{\rho \cdot L}{A}$（$\rho$ = 电阻率，$L$ = 长度，$A$ = 截面积）。电容器的引脚很细、电极箔很薄→截面积A小→电阻不可忽略。MLCC内部有上百层极薄金属电极，每层电阻叠加贡献了相当一部分ESR。高频下还有趋肤效应(skin effect)使电流只在导体表面薄层中流动，高频ESR比低频ESR更大。

**第二部分：介质损耗**

电容的介质材料在交变电场下，分子极化需要反复翻转，每次翻转消耗能量变成热量，等效为一个电阻。

不同电容ESR量级：
- 陶瓷电容(MLCC)：ESR很低（毫欧姆到几十毫欧姆）
- 铝电解电容：ESR较高（几十毫欧姆到几欧姆），主要是电解液离子导电电阻
- 钽电容：ESR中等

### A3. 寄生电感(ESL)的物理来源——电感如何产生

ESL = Equivalent Series Inductance，等效串联电感。

**电感产生的物理本质**：任何载流导体周围都会产生磁场（安培定律）。当电流变化时，磁场随之变化，变化的磁场反过来产生感应电动势（法拉第定律/楞次定律），阻碍电流变化。这种"自感"效应就是电感。

关键公式：$V_L = L \cdot \frac{di}{dt}$（电流变化越快，电感上反向电压越大）

**任何一段导线都有电感**，即使它是直的。一根长为l、半径为r的直导线，自感近似为：

$$L \approx \frac{\mu_0 \cdot l}{2\pi} \left[\ln\!\left(\frac{2l}{r}\right) - 1\right]$$

推论：导线越长→L越大；导线越细(r越小)→L越大。即使导线只有几毫米长也有零点几到几nH的电感。

**电容器中ESL的具体来源**：

```
PCB焊盘 → 引脚/端子 → 内部连接线 → 电极 → 内部连接线 → 引脚/端子 → PCB焊盘
```

这整条路径形成电流环路，每段导体都贡献自感，整个环路还有互感，全部加起来就是ESL。

- 来源1-引脚/引线：插件电容两根5~10mm引脚ESL可达15~20nH，这是ESL最大贡献者。贴片(SMD)没有长引脚所以ESL远小于插件。
- 来源2-内部电极结构：MLCC多层电极间电流环路贡献内部ESL。
- 来源3-封装尺寸：封装越大→路径越长→环路面积越大→ESL越大。

典型ESL值：0201约0.1~0.3nH、0402约0.3~0.5nH、0603约0.5~0.8nH、0805约0.8~1.2nH、1206约1.0~1.5nH。

- 来源4-PCB焊盘和过孔：焊盘布局和过孔也贡献额外串联电感。去耦电容过孔应打在焊盘旁边以减小这部分电感。

### A4. 为什么是串联模型（非并联）

电流路径是串行的：

```
端子A → [引脚电感+电阻] → [电极电阻] → [介质储能+损耗] → [电极电阻] → [引脚电感+电阻] → 端子B
```

电流**依次**流过所有部分，没有旁路可选。所以等效电路是串联：

```
端子A ---[ESL]---[ESR]---[C]--- 端子B
```

如果是并联模型，意味着电流可以选择只走电阻或只走电感。但物理上电流必须依次通过引脚→电极→介质，没有"绕路"选项。所以并联模型不符合物理现实。

### A5. 完整数值例子

假设0805封装、100nF、X7R陶瓷电容：C=100nF, ESR=50mΩ, ESL=1nH

$$f_{SRF} = \frac{1}{2\pi\sqrt{10^{-9} \times 10^{-7}}} \approx 15.9\text{MHz}$$

- $f = 1\text{MHz}$（容性区）：$X_c = 1.59\Omega$，$X_L = 0.006\Omega$ → $|Z| \approx 1.59\Omega$，容性主导
- $f = 15.9\text{MHz}$（SRF）：$X_c = X_L$ 抵消 → $|Z| = ESR = 0.05\Omega$，阻抗最小
- $f = 100\text{MHz}$（感性区）：$X_L = 0.628\Omega$，$X_c = 0.016\Omega$ → $|Z| \approx 0.63\Omega$，感性主导

在SRF之上，这个100nF电容的行为和一个1nH电感没有区别。

### A6. 寄生参数总结表

| 概念 | 物理来源 | 影响 |
|------|----------|------|
| ESR | 引脚/电极金属电阻 + 介质极化损耗 | SRF处最小阻抗、纹波发热、输出纹波电压 |
| ESL | 引脚/电极/环路的自感和互感 | 决定SRF上限、高频时电容变"电感" |
| 串联模型 | 电流依次流过引脚→电极→介质，无旁路 | $Z = ESR + j(\omega L - \frac{1}{\omega C})$ |

**核心认知**：你买的"电容"在高频下其实是个"电感"。理解这一点，就能理解为什么PDN设计需要多种容值并联、为什么去耦电容要选小封装、为什么焊盘过孔要靠近——一切都是为了对抗ESL。
