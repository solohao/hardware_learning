# 模拟电路知识点详解 —— 半导体器件完整知识链

> **知识因果链**：半导体掺杂 → PN结 → 二极管 → BJT三极管 → MOSFET
> 每一层知识都建立在前一层的基础之上

---

## 一、半导体基础

### 1. 本征半导体

纯净的硅(Si)或锗(Ge)称为本征半导体。硅有4个价电子，与相邻原子形成共价键。

在绝对零度时，所有电子都被共价键束缚，没有自由载流子，不导电。

温度升高后，部分电子获得足够能量挣脱共价键，成为**自由电子**，同时留下一个**空穴**。这个过程叫做**本征激发**。

$$\text{本征激发：} \text{共价键电子} \xrightarrow{\text{热能}} \text{自由电子} + \text{空穴}$$

本征半导体中：自由电子浓度 $n_i$ = 空穴浓度 $p_i$。

### 2. P型半导体（多子为空穴）

在硅中掺入**三价元素**（如硼B、铟In）：

- 硼只有3个价电子，与周围4个硅原子形成共价键时缺少1个电子
- 这个缺少的位置就是一个**空穴**
- 每掺入一个硼原子就多一个空穴

结果：
- **多数载流子（多子）= 空穴**
- 少数载流子（少子）= 电子（来自本征激发）
- 导电以空穴为主

> **考题要点**：P型半导体掺三价元素，多子是空穴。

### 3. N型半导体（多子为电子）

在硅中掺入**五价元素**（如磷P、砷As）：

- 磷有5个价电子，与周围4个硅原子形成共价键后多余1个电子
- 这个多余的电子成为自由电子
- 每掺入一个磷原子就多一个自由电子

结果：
- **多数载流子（多子）= 电子**
- 少数载流子（少子）= 空穴（来自本征激发）
- 导电以电子为主

> **考题要点**：N型半导体掺五价元素，多子是电子。

### 4. 关键概念辨析

| 概念 | P型 | N型 |
|------|-----|-----|
| 掺杂元素 | 三价（硼B） | 五价（磷P） |
| 多子 | 空穴 | 电子 |
| 少子 | 电子 | 空穴 |
| 掺杂原子称为 | 受主(Acceptor) | 施主(Donor) |
| 整体电中性？ | **是**（原子核带正电补偿） | **是** |

> **易错点**：P型半导体整体是**电中性**的（不是带正电！）。掺杂只是改变了载流子的相对数量，并没有改变总电荷。

## 二、PN结

### 1. PN结的形成

将P型和N型半导体紧密接触，在交界面处：

1. N区的多子（电子）向P区扩散（浓度高→低）
2. P区的多子（空穴）向N区扩散
3. 电子和空穴在交界面附近**复合**，消耗掉了该区域的自由载流子
4. 留下了不能移动的**离子**：P侧是负离子(受主离子)，N侧是正离子(施主离子)
5. 这些离子形成的区域叫做**空间电荷区（耗尽层/势垒区）**
6. 空间电荷区产生**内建电场**，方向从N指向P
7. 内建电场阻止进一步扩散 → 达到动态平衡

```
P型        耗尽层        N型
○○○○ | ⊖⊖⊖ ⊕⊕⊕ | ●●●●
○○○○ | ⊖⊖⊖ ⊕⊕⊕ | ●●●●
○○○○ | ⊖⊖⊖ ⊕⊕⊕ | ●●●●
       ←—— 内建电场 ——→
○=空穴  ●=电子  ⊖=负离子  ⊕=正离子
```

### 2. PN结正偏（正向偏置）

P接正极，N接负极：外加电场**削弱**内建电场 → 耗尽层**变窄** → 载流子能够越过势垒 → 大电流流过。

$$\text{正偏：耗尽层变窄，电阻很小，导通}$$

正向导通压降：硅约 $0.7V$，锗约 $0.2V$。

### 3. PN结反偏（反向偏置）

P接负极，N接正极：外加电场**增强**内建电场 → 耗尽层**变宽** → 只有极小的反向漏电流（少子漂移）。

$$\text{反偏：耗尽层变宽，电阻极大，截止}$$

反偏时的**结电容**：耗尽层相当于平行板电容器的介质层，两侧掺杂区相当于极板。

$$C_j = \frac{\varepsilon A}{W}$$

$W$ = 耗尽层宽度。反偏电压越大 → $W$ 越宽 → $C_j$ 越小。这就是**变容二极管**的原理。

### 4. PN结击穿

反向电压超过一定值后，电流急剧增大：

- **齐纳击穿(Zener)**：高掺杂+窄耗尽层，强电场直接将价电子拉出共价键。低压(<6V)
- **雪崩击穿(Avalanche)**：低掺杂+宽耗尽层，载流子在电场中加速碰撞产生新的电子空穴对，连锁反应。高压(>6V)

> **考题要点**：齐纳击穿低压、雪崩击穿高压；稳压管利用击穿特性工作。

## 三、二极管

### 1. 二极管 = 一个PN结 + 封装引线

二极管就是一个PN结加上引出的阳极(Anode=P侧)和阴极(Cathode=N侧)。

### 2. 二极管的伏安特性

$$I = I_S \left(e^{\frac{V}{nV_T}} - 1\right)$$

其中：
- $I_S$ = 反向饱和电流（极小，nA级）
- $V_T = \frac{kT}{q} \approx 26\text{mV}$（室温热电压）
- $n$ = 理想因子（1~2）

**正向**：$V > 0.7V$（硅），电流指数增长
**反向**：$V < 0$，电流 $\approx -I_S$（极小）
**击穿**：$V < -V_{BR}$，电流急剧增大

### 3. 常见二极管类型

| 类型 | 特点 | 典型应用 |
|------|------|----------|
| **普通整流二极管** | 正向压降0.7V，反向恢复慢 | 电源整流 |
| **肖特基二极管** | 金属-半导体结，压降0.2~0.4V，速度快 | 低压大电流整流、续流 |
| **稳压二极管(齐纳)** | 利用反向击穿稳压 | 电压基准、保护 |
| **变容二极管** | 利用反偏结电容随电压变化 | VCO调谐 |
| **发光二极管(LED)** | 正向导通时发光 | 指示、照明 |
| **光电二极管** | 反偏时光照产生光电流 | 光检测 |

### 4. 二极管关键参数

- **正向压降 $V_F$**：硅 $\approx 0.7V$，锗 $\approx 0.2V$，肖特基 $\approx 0.3V$
- **反向漏电流 $I_R$**：温度每升高10°C约翻倍
- **反向击穿电压 $V_{BR}$**
- **反向恢复时间 $t_{rr}$**：从正偏切换到反偏时，二极管需要时间"清除"存储电荷才能真正截止

> **考题要点**：硅二极管正向压降0.7V，锗0.2V；温度升高→正向压降减小（约-2mV/°C）

## 四、BJT三极管

### 1. BJT = 两个PN结

**NPN型**：N(发射极E) - P(基极B) - N(集电极C)

```
     C(集电极)
     |
     N
     |
  B--P--  (基极)
     |
     N
     |
     E(发射极)
```

发射结(BE结) + 集电结(BC结)

**PNP型**：P-N-P，电流方向相反。

### 2. BJT放大原理

NPN型为例，放大状态要求：**发射结正偏，集电结反偏**。

1. 发射结正偏 → 发射区(N)大量电子注入基区(P)
2. 基区很薄且掺杂浓度低 → 绝大多数电子来不及与空穴复合
3. 电子在集电结反偏电场作用下被"拉入"集电区
4. 结果：小的基极电流 $I_B$ 控制大的集电极电流 $I_C$

$$I_C = \beta \cdot I_B$$
$$I_E = I_C + I_B = (\beta + 1) \cdot I_B$$

$\beta$ = 电流放大倍数，通常50~300。

> **考题要点**：BJT是**电流控制型**器件，$I_B$ 控制 $I_C$。

### 3. BJT三种放大电路构型

| 构型 | 输入 | 输出 | 电压增益 | 电流增益 | 输入阻抗 | 输出阻抗 | 特点 |
|------|------|------|----------|----------|----------|----------|------|
| **共射极(CE)** | B-E | C-E | 高（反相） | $\beta$ | 中等 | 中等 | 电压电流均放大，最常用 |
| **共集电极(CC)** | B-E | E | $\approx 1$（同相） | $\beta+1$ | 高 | 低 | 射极跟随器，阻抗变换 |
| **共基极(CB)** | E-B | C-B | 高（同相） | $\approx 1$ | 低 | 高 | 高频特性好，电流缓冲 |

> **考题要点**：
> - 共射极：电压增益最高（用于放大）
> - 共集电极（射随器）：电压增益≈1，输入阻抗高、输出阻抗低（用于阻抗匹配/缓冲）
> - 共基极：电流增益≈1，高频性能好

### 4. BJT的温度特性

- $V_{BE}$ 具有**负温度系数**：约 $-2\text{mV/°C}$
- 温度升高 → $V_{BE}$ 减小 → $I_C$ 增大 → 温度进一步升高 → **热失控**
- 这就是BJT并联困难的原因——某个管子偏热→电流增大→更热→电流更大→烧毁

### 5. BJT开关特性

BJT用作开关时：
- **饱和导通**：$V_{CE(sat)} \approx 0.2\sim0.3V$（不可能为0！有PN结压降下限）
- **关断时有存储时间**：饱和时基区存储了大量少子，关断时需要先"抽走"这些少子，导致关断延迟
- 存储时间限制了BJT的最大开关速度

## 五、MOSFET

### 1. 从PN结到MOSFET——结构演变

MOSFET不是简单地堆叠PN结，而是引入了一个全新的概念：**场效应**。

```
        Gate(栅极)
          |
    ------+------
    |  SiO2绝缘层 |
    +-----------+
    |  P型衬底   |
   N+           N+
 Source        Drain
(源极)        (漏极)
```

- 源极和漏极是两个N+重掺杂区，嵌在P型衬底中
- 栅极通过SiO₂绝缘层与衬底**完全隔离**（这是"绝缘栅"的含义）
- Source-Body之间的PN结 = **体二极管**（无法消除）

### 2. 导通原理——反型层的形成

当 $V_{GS} = 0$ 时：Source和Drain之间被P型衬底隔开，两个背靠背PN结 → 不导通。

当 $V_{GS}$ 逐渐增大：
1. 栅极正电压通过SiO₂电容耦合到P型衬底表面
2. 正电压排斥空穴（P型多子），表面形成**耗尽层**（PN结知识的直接应用！）
3. 继续增大 → 吸引电子（P型少子）到表面
4. 当电子浓度 > 空穴浓度时，表面**反型**——P型变成了N型
5. Source和Drain之间形成N型**导电沟道**

$$\text{导通条件：} V_{GS} > V_{th}$$

### 3. MOSFET四种类型

| 类型 | 导通条件 | 特点 |
|------|----------|------|
| **N沟道增强型** | $V_{GS} > V_{th} > 0$ | 最常用，默认截止 |
| **N沟道耗尽型** | $V_{GS} > V_{th}$，$V_{th} < 0$ | 默认导通，需负压关断 |
| **P沟道增强型** | $V_{GS} < V_{th} < 0$ | 高侧开关常用 |
| **P沟道耗尽型** | $V_{GS} < V_{th}$，$V_{th} > 0$ | 较少用 |

**增强型**：制造时沟道无预掺杂 → 必须施加 $V_{GS}$ "增强"出沟道 → 默认截止
**耗尽型**：制造时沟道已预注入载流子 → $V_{GS}=0$ 时沟道已存在 → 默认导通

### 4. 三个工作区

**线性区**（$V_{DS} < V_{GS} - V_{th}$）：

$$I_D \approx \mu_n C_{ox} \frac{W}{L} (V_{GS} - V_{th}) \cdot V_{DS}$$

等效为可变电阻：

$$R_{DS(on)} \approx \frac{1}{\mu_n C_{ox} \frac{W}{L} (V_{GS} - V_{th})}$$

$V_{GS}$ 越大 → $R_{DS(on)}$ 越小。

**饱和区**（$V_{DS} \geq V_{GS} - V_{th}$）：

$$I_D = \frac{1}{2} \mu_n C_{ox} \frac{W}{L} (V_{GS} - V_{th})^2$$

$I_D$ 只与 $V_{GS}$ 有关 → 电压控制的恒流源。

**截止区**（$V_{GS} < V_{th}$）：$I_D \approx 0$。

### 5. 关键参数

**$R_{DS(on)}$（导通电阻）**：

$$P_{conduction} = I_D^2 \cdot R_{DS(on)}$$

正温度系数：温度升高 → 迁移率 $\mu_n$ 下降 → $R_{DS(on)}$ 增大。

$$R_{DS(on)}(T) \approx R_{DS(on)}(25°C) \cdot \left(\frac{T}{T_0}\right)^{\alpha}, \quad \alpha \approx 1.5 \sim 2.5$$

正温度系数带来天然**电流均衡**能力（与BJT的热失控形成对比）。

**寄生电容**：

$$C_{iss} = C_{GS} + C_{GD} \quad \text{（输入电容）}$$
$$C_{oss} = C_{DS} + C_{GD} \quad \text{（输出电容）}$$
$$C_{rss} = C_{GD} \quad \text{（反向传输电容/Miller电容）}$$

其中 $C_{DS}$ 就是PN结（体二极管）的反偏结电容——又回到了PN结的知识。

**$Q_g$（栅极电荷）**：驱动功率 $P_{gate} = Q_g \cdot V_{GS} \cdot f_{sw}$，高频应用选低 $Q_g$。

**体二极管**：Source-Body的PN结，N沟道中电流从S→D。反向恢复慢，死区时间内续流。

### 6. 开关过程与Miller平台

导通过程四阶段：
1. $V_{GS}$: 0 → $V_{th}$（给$C_{GS}$/$C_{GD}$充电，仍截止）
2. $V_{GS}$: $V_{th}$ → Miller平台（$I_D$上升，$V_{DS}$仍高）
3. **Miller平台**（$V_{GS}$不变，$V_{DS}$下降，驱动电流全部充$C_{GD}$）
4. $V_{GS}$继续上升到驱动电压（完全导通）

开关损耗：

$$P_{sw} = \frac{1}{2} V_{DS} \cdot I_D \cdot (t_{rise} + t_{fall}) \cdot f_{sw}$$

### 7. 在开关电源中的应用

**Buck高侧（控制管）**：承受开关损耗 → 选低 $Q_g$、低 $C_{oss}$
**Buck低侧（同步整流）**：主要导通损耗 → 选最低 $R_{DS(on)}$
**缓启动**：利用线性区可变电阻，缓慢升高 $V_{GS}$
**防反接**：利用体二极管

## 六、MOSFET vs BJT 综合对比

| 特性 | MOSFET | BJT |
|------|--------|-----|
| **控制方式** | 电压控制（$V_{GS}$） | 电流控制（$I_B$） |
| **输入阻抗** | 极高（栅极绝缘） | 较低 |
| **驱动功率** | 稳态几乎为零 | 需持续基极电流 |
| **导电载流子** | 多数载流子 | 少数载流子参与 |
| **开关速度** | 快（无存储时间） | 慢（有存储时间） |
| **温度系数** | $R_{DS(on)}$ 正温度系数 | $V_{BE}$ 负温度系数 |
| **并联使用** | 天然电流均衡 | 有热失控风险 |
| **导通压降** | $I_D \cdot R_{DS(on)}$（可以很小） | $V_{CE(sat)} \geq 0.2V$ |
| **关断泄漏** | 亚阈值电流 | $I_{CEO}$ |

**为什么MOSFET开关速度比BJT快？**

回到PN结基础：
- BJT的集电极电流涉及**少子**（电子注入P型基区→少子）。饱和时基区大量存储少子，关断时必须等少子复合或被抽走 → 存储时间 → 速度慢
- MOSFET导电靠沟道中的**多子**（N沟道中的电子就是N型的多子）。没有少子存储问题。关断只需放掉栅极电荷 → 速度快

## 七、知识因果链总结

```
半导体掺杂 → P型(多子=空穴) / N型(多子=电子)
    ↓
PN结 → 耗尽层 + 内建电场
    ↓       ↓           ↓
 正偏导通  反偏截止   反偏结电容
    ↓       ↓           ↓
  二极管  稳压管     变容二极管
    ↓
两个PN结 → BJT（电流控制，少子参与，有存储时间）
    ↓
PN结 + 绝缘栅 + 场效应 → MOSFET（电压控制，多子导电，无存储时间）
    ↓
MOSFET的体二极管 = Source-Body的PN结（又回到PN结！）
MOSFET的Cds = PN结反偏电容（又回到PN结！）
```

## 八、考题核心要点汇总

1. **P型掺三价元素(硼)，多子空穴；N型掺五价元素(磷)，多子电子**
2. **PN结正偏耗尽层变窄导通，反偏耗尽层变宽截止**
3. **硅二极管正向压降0.7V，锗0.2V**
4. **温度升高→正向压降减小（约-2mV/°C）**
5. **BJT电流控制($I_C = \beta I_B$)，共射极增益最高，射随器阻抗变换**
6. **BJT负温度系数→并联有热失控风险**
7. **MOSFET电压控制，导通条件 $V_{GS} > V_{th}$**
8. **$V_{GS}$ 增大 → $R_{DS(on)}$ 减小**
9. **$R_{DS(on)}$ 正温度系数 → 天然电流均衡，利于并联**
10. **$C_{iss}=C_{GS}+C_{GD}$，$C_{oss}=C_{DS}+C_{GD}$，$C_{rss}=C_{GD}$**
11. **低 $Q_g$/低 $C_{oss}$/低 $R_{DS(on)}$ 提升Buck效率**
12. **增强型默认截止，耗尽型默认导通**
