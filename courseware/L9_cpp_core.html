struct vs class · 构造析构 · 虚函数 vtable · RAII 与智能指针

1. struct vs class

C++ 中 struct 和 class 本质相同，主要区别是默认访问权限：

  • struct：默认 public。
  • class：默认 private。
  • 两者都可以有成员变量、成员函数、构造函数、继承、多态。
struct S {
    int x;        // 默认 public
};

class C {
    int x;        // 默认 private
};

快速检查

C++ 中 class 的默认访问权限是？

class 默认成员为 private，struct 默认 public。

2. 构造函数与析构函数

  • 构造函数：对象创建时自动调用，用于初始化成员、分配资源。
  • 析构函数：对象销毁时自动调用，用于释放资源、清理。
  • 没有返回值，函数名与类名相同，析构函数前加 ~。
class FileHandler {
    FILE *fp;
public:
    FileHandler(const char *path) { fp = fopen(path, "r"); }
    ~FileHandler() { if (fp) fclose(fp); }
};

快速检查

对象超出作用域时自动调用的是？

对象销毁时自动调用析构函数，用于资源释放。

3. 虚函数与 vtable

虚函数实现运行时多态：通过基类指针或引用调用派生类重写的函数。

  • 含虚函数的类会有一张 虚函数表（vtable），存储虚函数地址。
  • 每个对象有一个隐藏的 虚表指针（vptr），指向该类的 vtable。
  • 构造函数不能是虚函数（对象还没完整构造），析构函数建议为虚函数（防止派生类资源泄漏）。
class Base {
public:
    virtual void show() { printf("Base\n"); }
};

class Derived : public Base {
public:
    void show() override { printf("Derived\n"); }
};

Base *b = new Derived();
b->show();  // 输出 Derived

快速检查

下面哪种函数不能声明为虚函数？

构造函数不能是虚函数，因为构造时对象类型还未完全确定。

4. RAII 与智能指针

RAII（Resource Acquisition Is Initialization）：资源获取即初始化，对象生命周期绑定资源生命周期。

  • unique_ptr：独占所有权，自动释放，不能复制。
  • shared_ptr：共享所有权，引用计数归零时释放。
  • weak_ptr：弱引用，不增加引用计数，用于打破循环引用。
std::unique_ptr<int> p1(new int(10));
std::shared_ptr<int> p2 = std::make_shared<int>(20);
std::weak_ptr<int> wp = p2;

快速检查

哪种智能指针用于共享所有权？

shared_ptr 使用引用计数实现共享所有权。
