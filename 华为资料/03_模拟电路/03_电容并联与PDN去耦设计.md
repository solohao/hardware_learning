# 模拟电路知识点详解 —— 电容并联与PDN去耦设计

---

## 一、为什么要把电容并联？

电容并联在电源设计和信号完整性中无处不在，核心目的有三个：

### 1. 增大总容值

并联电容的总容值是各电容容值之和：

$$C_{total} = C_1 + C_2 + C_3 + \cdots + C_n$$

更大的容值意味着：
- 更好的低频滤波能力（$X_c = \frac{1}{2\pi f C}$，C大则Xc小）
- 更大的电荷储备，应对负载瞬态电流需求

### 2. 降低等效ESR

n个相同电容并联，等效ESR变为单个的 $\frac{1}{n}$：

$$ESR_{total} = \frac{ESR}{n}$$

这直接减小了ESR贡献的纹波：

$$V_{ripple,ESR} = \Delta I_L \cdot \frac{ESR}{n}$$

3颗电容并联，ESR纹波降为原来的1/3。

### 3. 降低等效ESL

$$ESL_{total} = \frac{ESL}{n}$$

ESL降低意味着：
- SRF提高（电容在更高频率下仍表现为容性）
- 高频尖峰减小

## 二、同容值并联 vs 不同容值并联

### 1. 同容值并联

$$C_{total} = n \cdot C, \quad ESR_{total} = \frac{ESR}{n}, \quad ESL_{total} = \frac{ESL}{n}$$

适用场景：需要更大容值和更低ESR的场合，如Buck输出滤波用多颗22uF MLCC并联。

### 2. 不同容值并联——宽频去耦的核心策略

不同容值的电容SRF不同：

$$f_{SRF} = \frac{1}{2\pi\sqrt{ESL \cdot C}}$$

- **大容值(如100uF)**：SRF低（约几百kHz），覆盖**低频段**去耦
- **中容值(如1uF)**：SRF中等（约几MHz），覆盖**中频段**
- **小容值(如100pF)**：SRF高（约几百MHz），覆盖**高频段**

三者并联后，整体阻抗曲线在宽频范围内都保持较低：

```
阻抗 |
     |  100uF     1uF      100pF
     |   \_       \_        \_
     |    \_       \_        \_
     |     \__   ___\__   ____\_
     |        \_/      \_/      \___
     |   
     |  ← 三者并联后的总阻抗包络线很低 →
     |                              频率 →
```

这就是PDN(电源分配网络)设计的基本思路：**用不同容值的电容覆盖不同频段，实现宽频低阻抗**。

典型PDN去耦电容配置：
- **Bulk电容**（100~470uF电解/钽）：覆盖 <100kHz
- **中间电容**（1~10uF MLCC）：覆盖 100kHz~10MHz
- **高频电容**（10nF~100nF MLCC）：覆盖 10MHz~几百MHz
- **超高频**：依赖PCB电源/地平面间的平板电容

## 三、并联电容的陷阱——反谐振

### 1. 什么是反谐振？

当两个不同容值的电容并联时，在两者SRF之间的某个频率处，会出现**反谐振(Anti-resonance)**，阻抗突然升高，形成一个尖峰。

### 2. 物理机制

以大电容（100uF）和小电容（100nF）并联为例：

在某个频率 $f_{anti}$ 处：
- 100uF已经超过了它的SRF → 表现为**电感**（阻抗 $j\omega L$）
- 100nF还没到达它的SRF → 表现为**电容**（阻抗 $\frac{1}{j\omega C}$）

一个电感和一个电容并联 → 这就是一个**并联谐振电路**！

并联谐振时阻抗趋于极大值：

$$Z_{parallel} = \frac{Z_1 \cdot Z_2}{Z_1 + Z_2}$$

当 $Z_1 = j\omega L$（大电容感性区）且 $Z_2 = \frac{1}{j\omega C}$（小电容容性区）满足 $\omega L = \frac{1}{\omega C}$ 时，分母趋于零，阻抗趋于无穷大。

实际中由于ESR的存在，阻抗不会真正无穷大，但会出现一个**明显的阻抗尖峰**。

```
阻抗 |       反谐振尖峰
     |          /\
     |   \_    /  \    /_
     |    \_  /    \  / \_
     |     \_/      \/    \_
     |                      
     |   大C的    ↑    小C的
     |   SRF   f_anti  SRF
     |                        频率 →
```

### 3. 反谐振的危害

- 反谐振频率处阻抗很高 → 该频段去耦能力差
- 如果IC在该频率有较大的电流需求 → 电源电压波动大 → 可能导致逻辑错误

### 4. 如何缓解反谐振？

**方法1：增加中间容值**

在大电容和小电容之间插入中间容值的电容。例如100uF和100nF之间加入1uF、10uF。容值梯度越平滑，反谐振尖峰越小。

**方法2：选择低ESR电容**

ESR相当于反谐振电路中的阻尼电阻。ESR越大（相对而言），反谐振尖峰越被压制（但ESR大本身也不好）。MLCC的ESR极低，反谐振尖峰可能更尖锐，需要更注意容值梯度。

**方法3：增加同容值电容的数量**

多颗相同容值电容并联不会产生反谐振（SRF相同），只会降低ESR和ESL。

**方法4：利用PCB平面电容**

电源层和地层之间的平板电容提供连续的高频去耦，天然没有反谐振问题。

## 四、并联电容的摆放位置

### 1. 距离IC的远近

不同容值的电容应该按照其有效频段摆放：

- **高频小电容(100nF)**：紧贴IC电源引脚，距离越近越好（减小走线ESL）
- **中频电容(1~10uF)**：在IC附近，距离稍远可接受
- **低频大电容(100uF+)**：可以放在电源入口或板边，距离IC较远没关系

原因：高频信号波长短，走线电感影响大；低频信号波长长，走线电感影响小。

### 2. 过孔对ESL的影响

电容焊盘到电源/地平面的过孔也贡献ESL。一个标准过孔约0.5~1nH。

减小过孔ESL的方法：
- 过孔紧邻焊盘（而非远离）
- 每个焊盘打多个过孔（并联降低ESL）
- 使用大孔径过孔

## 五、工程实例

### 典型FPGA电源去耦方案

一个FPGA的1.0V核心电源，电流需求3A，纹波要求<30mV：

| 位置 | 电容 | 数量 | 作用 |
|------|------|------|------|
| 电源入口 | 470uF/6.3V 铝电解 | 1 | Bulk储能，覆盖<10kHz |
| IC附近2cm | 22uF/6.3V 0805 MLCC | 4 | 中低频去耦，100kHz~5MHz |
| IC附近1cm | 1uF/6.3V 0402 MLCC | 8 | 中频去耦，1MHz~50MHz |
| 紧贴引脚 | 100nF/16V 0201 MLCC | 12 | 高频去耦，10MHz~500MHz |

总容值：470uF + 88uF + 8uF + 1.2uF ≈ 567uF
等效ESR：由12颗0201 MLCC主导 ≈ 0.3mΩ

这个方案实现了从DC到500MHz的宽频低阻抗覆盖。

## 六、考题对应要点

1. **多个不同容值电容并联**：覆盖宽频段去耦，大电容管低频，小电容管高频
2. **并联降低ESR/ESL**：n颗并联则ESR和ESL各降为1/n
3. **反谐振**：不同容值并联在两者SRF之间出现阻抗尖峰，通过增加中间容值缓解
4. **去耦电容靠近IC**：高频电容紧贴引脚，减小走线ESL
5. **多相并联减小纹波**：不仅是电容并联，Buck多相交错也能使纹波电流部分抵消
