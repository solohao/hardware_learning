## 一、整体考点方向概述

本批次5套题目共约**200道题**，延续了前15套的核心知识体系，同时在以下方向有所深化：

1. **高速信号完整性深化**：过孔stub/背钻、差分信号参考平面、跨分割影响、插损因素
2. **电源设计与管理**：PDN阻抗优化、DCDC效率计算、LDO内部结构、电源噪声综合治理
3. **数字逻辑与CPU架构**：流水线级数、CISC/RISC对比、哈佛/冯诺依曼、Cache写策略
4. **接口协议与电平标准**：CML/LVPECL/LVDS深入对比、OD门/OC门特性、电平转换方案
5. **可靠性与工程规范**：浴盆曲线深化、EMI/EMC、散热设计、IO上下电时序
6. **模拟电路基础**：运放差分电路、PN结正反向特性、增强型MOSFET导通条件、差分/共模信号

### 📌 2. 电源设计与管理

| 考点细项 | 涉及套数 | 具体题目关键词 |

| LDO内部核心构成 | 17套 | 基准电压源 + 差分放大器（运放）+ MOS管；**不包含电感**（LDO是线性稳压） |

| BUCK效率提升 | 23套 | 选择更低**Coss、Rdson、Qg**的MOS管；降低开关速度→效率降低；减小感量→纹波增大 |
| DCDC损耗计算 | 23套 | 负载功率=V×I=1.0V×2A=2W；输入功率=2W÷80%=2.5W；**损耗=0.5W** |
| DC-DC输入口滤波 | 23套 | **高频+低频滤波电容组合**效果最好（覆盖宽频率范围） |
| Buck电路减小纹波 | 18套 | 多相并联、提高开关频率、增大滤波电感量；输出滤波电容由陶瓷改为电解**不能**减小纹波 |
| 总线电容计算 | 18套 | 12V总线最低8V、跌落400μs、负载10A→C=I×t/ΔV=10×0.0004/4=**1000μF** |
| 电源纹波测试 | 18套 | 同轴电缆+10μF电容隔直+示波器50Ω DC模式（最佳方案） |
| 节能场景MOS vs 三极管 | 17套 | 反向电路中**MOS管**更合适（导通电阻低、功耗小） |
| 动态调频调压DVFS | 17、22套 | DVFS是功耗优化的常用手段（**正确**）；根据负载动态调整电压和频率 |
| 数字电路功耗与温度 | 前套复现 | 环境温度升高→功耗上升（漏电流增加） |
| CMOS静态功耗组成 | 23套 | 栅极漏电 + 亚阈值漏电 + 反偏PN结漏电；**开关功耗不属于**静态功耗 |

### 📌 3. 信号完整性（SI）

| 考点细项 | 涉及套数 | 具体题目关键词 |
|---------|---------|--------------|
| PCB过孔背钻作用 | 17套 | 主要作用是减少信号**插损**（非串扰/反射）；背钻去除stub |
| 过孔stub消除技术 | 17、22套 | **背钻、盲孔、增加地过孔**有效；低损耗板材不能直接解决stub问题 |
| 差分信号参考平面 | 17、22套 | 差分信号返回电流主要在**参考平面**（非另一条线）；参考平面**非常重要**；差分对与其他信号线间距仍需控制 |
| 传输线跨分割影响 | 16套 | 阻抗失配 + 串扰增大 + EMC问题 + 回流路径增大（**全选**） |
| 消除传输线反射方法 | 23套 | 减小走线长度（√）、源端匹配（√）、终端匹配（√）；**终端与地之间加电容不能**消除反射 |
| 相邻层减小干扰走线 | 23套 | **垂直走线**最优（非平行/45°交叉） |
| 信号上升时间与带宽 | 23套 | 上升时间越小→高频分量越多→带宽**越大**（BW≈0.35/Tr） |
| 高速链路插损因素 | 17、22套 | 板材类型、线厚、铜皮粗糙度、线宽（**全选**） |
| 高速PCB板材关键特点 | 17套 | 区别于普通板材的关键点：**单位长度走线插损小** |
| PCB特征阻抗因素 | 16、23套 | 参考层距离变小→阻抗变小（√）；介电常数变大→阻抗变小（√）；线宽变大→阻抗**变小**（非变大！16套C选项为错误项） |
| 微带线等效介电常数 | 17套 | 介于空气介电常数与介质介电常数**之间**（电磁场同时存在于介质和空气中） |
| 减小串扰手段 | 17、22、23套 | 增加线间距、减少并行走线长度、选择慢变化边沿器件；**负载增加PF电容**也有一定效果（滤高频）；驱动电流大小、信号跃变时间、参考平面间距影响串扰；**高电平持续时间不影响** |
| 常见SI问题 | 16套 | 回沟、同步开关噪声(SSN)、串扰与耦合、过冲&下冲（**全选**） |
| 信号过冲减小 | 前套复现 | 减小驱动电流、降低信号边沿斜率、增大始端匹配电阻 |
| 数字信号传输带宽判断标准 | 16套 | 信号**上升下降时间**决定所需传输带宽（非频率/幅度/能量分布） |
| 示波器带宽选择 | 16套 | 测量156.25MHz差分时钟（Rise/Fall<100ps）需要带宽为被测信号3-5倍→**5GHz**以上 |
| 示波器整体带宽 | 17套 | 整体带宽**小于**示波器和探头的带宽最小值（系统带宽公式：1/BW²=1/BW₁²+1/BW₂²） |
| Serdes眼图宽度影响 | 16套 | **抖动(Jitter)**没处理好直接影响眼图宽度；Skew影响数据对齐；频率准确度和时钟周期不直接影响宽度 |
| 路径延时因素 | 16套 | 受**工艺、温度、长度**等因素影响，时序分析需考虑最大延时和最小延时（**正确**） |
| 通孔寄生参数 | 23套 | 通孔寄生电感和寄生电容都重要；通孔**长度**对电感影响比孔径更大（非孔径比长度大） |

### 📌 4. 数字逻辑与接口协议

| 考点细项 | 涉及套数 | 具体题目关键词 |
|---------|---------|--------------|
| 线与功能实现 | 16、25套 | **集电极开路门(OC门)**可实现线与（确定）；三态输出门16套认为可以、25套认为不可以（**存争议**）；与非门不能 |
| OC门/OD门输出状态 | 16、17、22套 | OC门（不含上拉）输出：**低电平+高阻**（无高电平能力）；OD门可实现电平转换和线与；推挽输出低电平能力**不比**OD门强很多；上拉电阻太大→上升沿变缓 |
| 开漏输出优点 | 17、22套 | **电平转换 + 线与**；高电平驱动能力弱（取决于外部上拉）；输出电压取决于外部上拉电源（非芯片IO供电） |
| PLL基本组成 | 16套 | 鉴相器 + 环路滤波器 + 压控振荡器 + 分频器；**放大器不属于**PLL基本组成 |
| 噪声容限 | 16套 | 3.3V TTL/CMOS中Vohmin-Vihmin和Vilmax-Volmax应≥**0.4V** |
| 3.3V LVTTL电平参数 | 16套 | VOH≥2.4V，VOL≤0.4V，VIH≥2V，VIL≤0.8V（与5V TTL相同）；区别于2.5V LVTTL和CMOS电平 |
| 3.3V CMOS不可靠区域 | 17、22套 | 0.8V~2.0V属于**不可靠区域**，实际使用中要避免（正确） |
| 竞争与冒险 | 16套 | 有冒险**不一定**存在竞争；有竞争**不一定**存在冒险（独立但相关现象） |
| 消除竞争的方法 | 18套 | **同步时序电路**可消除竞争；异步电路不行 |
| 时序逻辑避免毛刺 | 23套 | 采用时序逻辑可避免毛刺，使电路更稳定（**正确**） |
| 组合逻辑电路 | 18套 | 译码器属于组合逻辑；计数器、移位寄存器、触发器属于时序逻辑 |
| 译码器不能实现的功能 | 18套 | 可实现多路数据分配器、地址译码、七段显示驱动；**不能实现计数器** |
| D触发器最高工作频率 | 17、22套 | Tclk=Tu+Tco（建立时间+时钟到输出）；fmax=1/(Tu+Tco)=1/5ns=**200MHz** |
| 建立时间定义 | 18套 | 时钟上升沿到来**之前**数据必须稳定的时间 |
| Pipeline ADC特点 | 16套 | 采样率高、分辨率中等、**精度高**（非低）、**功耗低**（非高） |
| ADC失调误差计算 | 16套 | 10bit ADC，Vref=2.048V，1LSB=2.048V/1024=**2mV**；失调+3LSB→输出全0时实际输入=3×2mV=**6mV** |
| 10位DAC分辨率 | 16套 | 分辨率=1/2^n=**1/1024** |
| ADC工作过程 | 17、22套 | 采样→量化→编码；**滤波不是**ADC工作过程 |
| 整流与逆变 | 16套 | 整流=交流→直流；逆变=直流→交流 |
| 补码表示 | 16、18套 | 8位补码（4个1和4个0）：最大值=0111_1000=**120**；最小值=1111_0000=**-16** |
| 同或运算 | 18套 | 同或：相同→1，不同→0；0x5A⊙0xA5=**0x00**（正确，每位相反） |

### 📌 5. 通信协议与接口电平

| 考点细项 | 涉及套数 | 具体题目关键词 |
|---------|---------|--------------|
| CML/LVPECL/LVDS对比 | 16、17套 | **CML**：超高速串行互连；**LVPECL**：时钟用，低抖动，**强驱动**（非低功耗）；**LVDS**：低摆幅(350mV)，低功耗，电流驱动，100Ω端接 |
| LVPECL电路特性 | 17套 | 功耗较大（非低），直流分量14mA；对噪声不敏感，低EMI；需要外加直流偏置（VCC-1.3V）；输出为射极跟随器（**低阻抗**非高阻抗） |
| RS-232逻辑电平 | 17、23套 | 逻辑"1"=-3V~-15V；逻辑"0"=+3V~+15V |
| RS-232校验方式 | 18套 | 采用**奇偶校验**（非CRC/海明码） |
| I2C协议 | 17套 | 通过**地址寻址**方式通信；非全双工；非CS片选；信号线为2根（SDA+SCL） |
| I2C低电平浮高优化 | 23套 | **加大驱动能力 + 减小上拉电阻**可优化；增大上拉电阻/减小驱动能力反而恶化 |
| SPI通信 | 17套 | **MOSI**引脚用于主机输出数据（Master Out Slave In） |
| PCI总线 | 18套 | PCI总线宽度为**32/64位**（非16位）；地址/数据线复用；支持即插即用 |
| PCIe总线分层 | 23套 | 物理层 + 数据链路层 + 事务层（**会话层不属于**） |
| DDR4地址/控制信号电平 | 23套 | DDR4 Addr/CTRL使用**LVCMOS**电平（非POD/LVTTL/SSTL） |
| SPI片选信号 | 23套 | 读写过程中CS片选信号始终为**低电平**（低有效）；数据采样支持上升沿和下降沿（取决于模式） |
| 超线程技术 | 23套 | 在**一个CPU内核上**同时运行多个线程（非多进程/多核运行一个线程） |
| TDM同步要求 | 16套 | 需要满足**频率同步+时间同步**（非仅频率/时钟） |
| 差模/共模干扰 | 23套 | 差模干扰在两导线间传输，属对称性干扰；共模干扰电流大小相等、方向**相同**；共模属于**对称性**干扰（非非对称性）；差模电流大小**不一定相等** |
| 误码率 | 23套 | **误码率**是衡量数字通信系统传输质量的关键指标 |
| 波特率与比特率 | 18套 | 二进制信号传输时波特率=比特率（**正确**）；多进制时比特率=波特率×log₂(M) |
| 电平转换方式 | 23套 | 可用：三极管、光耦、NMOS管；**电容分压不能**进行电平转换（DC稳态后断路） |

### 📌 6. CPU架构与存储器

| 考点细项 | 涉及套数 | 具体题目关键词 |
|---------|---------|--------------|
| CPU处理流程 | 16套 | Fetch(读取)→**Decode(解码)**→Execute(执行)→Writeback(写回) |
| 多核处理器Core | 16套 | Core是**处理单元**（非存储/IO/内存单元） |
| 流水线级数与效率 | 17、22套 | 流水线级数**非越深越好**；过深→控制逻辑复杂、停顿增多、开销累积抵消收益 |
| CISC指令集特点 | 17、22套 | 单条指令功能强大易编程；寻址方式复杂耗时多；指令种类多；**不能**一个周期处理完一条指令 |
| 哈佛 vs 冯诺依曼 | 17、22套 | 哈佛：程序/数据总线**分开**，可并行处理→数据传输更快（非更慢）；冯诺依曼：共用总线；哈佛结构**不一定**成本更低；安全性无明确定论 |
| Cache目的 | 16套 | 解决CPU和主存之间的**速度匹配**问题（非扩容） |
| Cache对程序员透明 | 前套复现 | Cache对程序员**透明**（程序员不直接操作） |
| Cache写策略 | 18套 | Write Back：只写Cache，替换时写主存（效率高，结构复杂）；Write Through：直接写主存（结构简单，效率低）（正确） |
| Cache描述 | 23套 | 理论基础：**程序局部性原理**；弥补CPU和内存性能差异；长时间未使用数据**不会一直保存** |
| 存储器速度排序 | 16套 | **Cache > DDR > Flash > HDD** |
| SRAM vs DRAM | 18套 | DRAM用电容保存信息，需定时刷新；SRAM用触发器，不需刷新；**DRAM集成度高于SRAM** |
| DRAM上电内容 | 18套 | DRAM上电时内容**不确定**（不是全0）；Flash上电可能全1 |
| DRAM读写速度 | 23套 | 读写访问速度排序：**DRAM > NandFlash > 机械硬盘 > 磁带** |
| 8086 CPU内部单元 | 18套 | **EU(执行单元) + BIU(总线接口单元)**；ALU是EU的组成部分 |

## 五、易错考点提示

| 易错描述 | 正确理解 |
|---------|---------|
| 走线变宽→特征阻抗变大 | ❌ 走线变宽→分布电容增大→特征阻抗**变小** |
| 差分信号不需要参考平面 | ❌ 差分信号回流主要集中在**参考平面**，非常重要 |
| 增强型MOS管Vgs=0可导通 | ❌ 增强型需Vgs>Vth才能形成导电沟道；**耗尽型**Vgs=0可导通 |
| 低频时趋肤效应明显 | ❌ 趋肤效应在**高频**时明显；低频时电流均匀分布 |
| PLL基本组成包含放大器 | ❌ PLL基本组成：鉴相器+环路滤波器+VCO+分频器；**不含放大器** |
| 流水线级数越深效率越高 | ❌ 过深→控制复杂、停顿增多、开销累积，**非越深越好** |
| OD门可组成推挽输出且低电平能力更强 | ❌ 推挽输出低电平能力**不比OD门强很多** |
| LDO内部包含电感 | ❌ LDO是**线性**稳压器，内部无电感；含电感的是DC-DC |
| 提高负载电流跳变斜率可改善PDN | ❌ 电流跳变更快→V=L×di/dt增大→PDN**恶化** |
| 电容分压可进行电平转换 | ❌ 电容DC稳态后**断路**，不能实现稳定电平转换 |
| 共模干扰属于非对称性干扰 | ❌ 共模干扰电流方向相同，属于**对称性**干扰 |
| 输出功率越大功放管功耗越大 | ❌ 效率可能提高，功耗**不一定**随输出功率线性增大 |
| 通孔孔径对电感影响比长度更大 | ❌ 通孔**长度**对电感影响比孔径更大 |
| 开关功耗属于CMOS静态功耗 | ❌ 开关功耗是**动态功耗**；静态功耗=漏电（栅极+亚阈值+反偏PN结） |
