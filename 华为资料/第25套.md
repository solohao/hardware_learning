1、采用虚拟存储器的目的是（）
A.扩大辅存容量
B.扩大主存容量
C.提高辅存访问速度
D.提高主存利用率
答案：B
解析：虚拟存储器的目的是扩大主存容量。在计算机系统中，主存（内存）的容量往往
是有限的，而程序和数据的规模可能会很大。虚拟存储器通过将一部分暂时不使用的程
序和数据存放到辅存（如硬盘）中，当需要使用时再调入主存。这样，从用户的角度来
看，就好像拥有了一个比实际主存大得多的存储空间，达到了扩大主存容量的效果。
选项 A，虚拟存储器不是为了扩大辅存容量，辅存容量本身通常较大，无需通过虚拟存
储器来扩大。
选项 C，虚拟存储器并不能提高辅存访问速度，其重点在于解决主存容量不足的问题。
选项 D，提高主存利用率不是采用虚拟存储器的主要目的。
综上所述，采用虚拟存储器的目的是扩大主存容量，选择选项 B。
2、现在有一个两输入（A,B）的与非门，想要将其当作反相器使用，则输入端 A、B 的
连接方式为（）
A.A 和 B 都接“1”
B.A 或者 B 中有一个接"0"
C.都不是
D.A 与 B 相连
答案：D
解析：与非门输出为低电平仅当两输入均为高电平（1），否则输出高电平（0）。将 A、B
相连后，输入信号同时作用于两个输入端：当输入为高电平时，两输入均为高，输出低
电平（取反）；当输入为低电平时，两输入均为低，输出高电平（取反）。此逻辑等效于
非门功能。若 A/B 独立控制（如选项 A/B），则无法实现完整反相功能。
3、一个 D 触发器,其数据 Tsu＝2ns，Tcq＝3ns，Thd＝1ns，则此触发器的最高工作频率
为：
A.500HMz
B.200HMz
C.333HMz
D.100HMz
答案：B
解析：对于一个 D 触发器，其最高工作频率取决于建立时间（Tsu）、保持时间（Thd）
和时钟到输出的延迟时间（Tcq）。
最 小 的 时 钟 周 期 Tmin 应 为 Tsu 、 Tcq 和 Thd 之 和 ， 即
Tmin=Tsu+Tcq+Thd=2ns+3ns+1ns=6ns。
而工作频率 f=1/T，所以最高工作频率为 fmax=1/Tmin=1/6ns≈166.7MHz。
四个选项中最接近的是 200MHz。所以答案是 B。
4、设 A＝186，B＝2730，C＝0xBB，它们之间的大小关系是
A.A＜C＜B
B.A＞B＞C
C.A＜B＜C
D.A＜B＝C
答案：A
解析：先将十六进制数 C＝0xBB 转换为十进制数。十六进制数 0xBB 中，B 代表十进制
的 11。
转换方法为按权展开相加，即 0xBB＝11×161＋11×160＝176＋11＝187。
然后比较 A＝186、B＝2730、C＝187 的大小。
显然 186＜187＜2730，也就是 A＜C＜B。综上所述，答案是 A 选项。
5、晶体三极管的饱和条件，下列说法正确的是___
A.发射结反偏,集电结正偏
B.发射结正偏,集电结正偏
C.发射结反偏,集电结反偏
D.发射结正偏,集电结反偏
答案：B
解析：晶体三极管有三种工作状态：截止、放大和饱和。对于饱和状态，其条件是发射
结正偏，集电结正偏。发射结正偏使得大量载流子注入基区，当集电结也正偏时，集电
极收集载流子的能力下降，使得三极管进入饱和状态，此时三极管的电流很大，而电压
降很小。
A 选项发射结反偏，集电结正偏是错误的，这种情况三极管处于截止状态。
C 选项发射结反偏，集电结反偏，三极管处于截止状态。
D 选项发射结正偏，集电结反偏是三极管处于放大状态的条件。
综上所述，正确答案是 B。

A.2.5VCMOS 逻辑电平的 VOH 为 2.0V，而 3.3VTTL/CMOS 的逻辑电平的 VIH 也为

B.5VTTL 器件可以直接驱动 5Vcmos 器件
C.5Vcmos 器件可以直接驱动 3.3VTTL/CMOS 器件，也可以通过 LVC/LVT 器件（输入
是 TTL/CMOS 逻辑电平，输出是 LVTTL 逻辑电平）进行转换
D.3.3VTTL/CMOS 器件可以直接驱动 5VTTL 器件

选项 D：3.3VTTL/CMOS 器件输出的高电平低于 5VTTL 器件所要求的输入高电平，直
接驱动会导致信号错误，所以 D 错误。
7、流水线级数是影响处理器效率的重要因素，流水线级数越深，CPU 执行效率越高
A.错误
B.正确
答案：A
解析：虽然流水线级数增加在一定程度上可能会提高处理器的时钟频率，但是流水线级
数并不是越深，CPU 执行效率就越高。随着流水线级数的加深，会带来一些负面影响。
例如，分支预测错误的代价增大，一旦预测错误，需要清空后续指令重新填充；还会增
加流水线的控制逻辑复杂度，带来额外的开销；以及可能出现的流水线阻塞、数据冒险
和控制冒险等问题更加频繁和复杂，导致性能下降。
所以，不能简单地认为流水线级数越深，CPU 执行效率越高。
8、以下关于电子器件失效浴盆曲线的描述，正确的是（）
A.早期失效可以通过筛选试验避免
B.偶然失效期中失效率急剧增加
C.损耗失效发生在产品生命周期使用期间，失效率低且稳定
D.早期失效主要由缺陷和设计错误引起
答案：A
解析：首先来看选项 A，早期失效通常是由于制造过程中的缺陷或者原材料的问题导致
的。通过筛选试验，可以提前发现并排除那些存在潜在缺陷的产品，从而避免早期失效，
该选项正确。
选项 B，偶然失效期的特点是失效率低且稳定，并非失效率急剧增加，所以该选项错误。
选项 C，损耗失效发生在产品使用的后期，此时失效率会急剧上升，而不是失效率低且
稳定，此选项错误。
选项 D，早期失效主要是由制造过程中的缺陷或者原材料的问题引起的，而非主要由缺
陷和设计错误引起，所以该选项错误。
综上所述，正确的是选项 A。
9、信号输出产生毛刺的原因主要是
A.串扰
B.阻抗不匹配
C.双向管脚输入输出状态切换
D.数字逻辑的竞争冒险
答案：D
解析：选项 A，串扰会对信号产生干扰，但通常不是产生毛刺的主要原因。串扰主要表
现为相邻信号之间的相互影响，可能导致信号的幅度、相位等发生变化，但一般不会直
接产生毛刺。
选项 B，阻抗不匹配主要影响信号的传输质量和反射等问题，可能导致信号失真、衰减
等，但不是产生毛刺的主要原因。
选项 C，双向管脚输入输出状态切换可能会引起一些信号变化，但通常也不是产生毛刺
的主要因素。
选项 D，数字逻辑的竞争冒险是信号输出产生毛刺的主要原因。在数字电路中，由于不
同路径的信号传输延迟不同，当输入信号发生变化时，可能会导致逻辑门的输出在短时
间内出现不确定的状态，从而产生毛刺。综上所述，答案是 D。
10、PCB 设计中地平面说法错误的是
A.穿过地平面的过孔应避免连成线
B.地平面的完整性有助于信号的回流
C.应尽量保证完整的地平面
D.穿过地平面的过孔应保证最小的总面积
答案：D
解析：首先，我们来看选项 A，穿过地平面的过孔避免连成线是合理的做法，因为过孔
连成线可能会影响地平面的性能，所以选项 A 是正确的说法。
选项 B，地平面的完整性确实有助于信号的回流，能够提供良好的信号返回路径，这也
是正确的观点。
选项 C，尽量保证完整的地平面能够优化电路性能，减少干扰，是常见且正确的设计原
则。
而选项 D，“穿过地平面的过孔应保证最小的总面积”这种说法是错误的。在 PCB 设计中，
重点通常不是关注过孔的总面积大小，而是避免过孔的不当布局影响地平面的完整性和
性能。
综上所述，说法错误的是选项 D。
11、DDR 为高速并行总线接口，SI 设计贯穿整个产品硬件设计过程。在某特定速率下，
下面哪个因素不会影响 DDR 的 SI 时序窗口 margin?
A.DDRODT 配置
B.DDRRon 配置
C.DDRCAparity 配置
D.DDRVref 配置
答案：C
解析：A 选项，DDRODT 配置会影响信号的终端匹配，从而影响信号的质量和时序，
可能会影响到 SI 时序窗口 margin。
B 选项，DDRRon 配置会改变内存芯片的内阻，进而影响信号的驱动能力和传输特性，
也可能对 SI 时序窗口 margin 产生影响。
C 选项，DDRCAparity 配置主要是用于数据校验，与信号传输的电气特性和时序关系不
大，通常不会影响 DDR 的 SI 时序窗口 margin。
D 选项，DDRVref 配置会影响信号的判别阈值，对信号的采样和时序有影响，从而可能
影响到 SI 时序窗口 margin。
综上所述，选择 C 选项，DDRCAparity 配置不会影响 DDR 的 SI 时序窗口 margin。
12、RS-232 电平标准的逻辑"1"对应的电压是多少?
A.0V
B.3.3V
C.﹢3V~﹢15V
D.-3V~-15V
答案：D

13、如果一个单 bit 信号 a 延时 1 拍和延时 2 拍的结果为 a_1d 和 a_2d，那么 a_1d&
（~a_2d）的功能是（）
A.取信号边沿有效
B.取信号上升沿
C.取信号下降沿
D.对信号计数
答案：C
解析：A 选项“取信号边沿有效”：通常边沿有效包括上升沿和下降沿，单纯的 a_1d&
（~a_2d）并不能直接表示取信号边沿有效。
B 选项“取信号上升沿”：当信号从 0 变为 1 时为上升沿。延时 1 拍的结果 a_1d 表示当前
时刻的前一时刻的信号值，延时 2 拍的结果 a_2d 表示当前时刻的前两时刻的信号值。
（~a_2d）表示对 a_2d 取反。当 a 从 0 变为 1 时，即当前时刻为 1，前一时刻为 0，前
两时刻也为 0。此时 a_1d 为 0，（~a_2d）为 1，a_1d&（~a_2d）的结果为 0，不符合上
升沿的判断。
C 选项“取信号下降沿”：当信号从 1 变为 0 时为下降沿。当 a 从 1 变为 0 时，当前时刻
为 0，前一时刻为 1，前两时刻不管是 1 还是 0。此时 a_1d 为 1，（~a_2d）为 1，a_1d&
（~a_2d）的结果为 1，符合下降沿的判断。
D 选项“对信号计数”：a_1d&（~a_2d）的操作并不是对信号进行计数。
综上所述，a_1d&（~a_2d）的功能是取信号下降沿，选择 C 选项。
14、陶瓷电容施加偏置电压后实际有效容值会怎么样变化
A.不确定
B.不变
C.变小
D.变大
答案：C
解析：陶瓷电容具有压电特性。当施加偏置电压时，电介质内部的极化会发生变化，导
致有效介电常数降低。由于电容的容量值与介电常数成正比，介电常数降低，电容的实
际有效容值也就随之变小。所以，陶瓷电容施加偏置电压后实际有效容值会变小。
15、请选择一下容量密度最大的介质（）
A.QLC
B.PLC
C.SLC
D.TLC
答案：B
解析：SLC（Single-LevelCell），即单层式存储，一个存储单元只存储 1 位数据，其特点
是速度快、寿命长，但容量密度相对较低。
QLC（Quad-LevelCell），即四层式存储，一个存储单元存储 4 位数据。
PLC（Penta-LevelCell），即五层式存储，一个存储单元存储 5 位数据。
TLC（Triple-LevelCell），即三层式存储，一个存储单元存储 3 位数据。
存储单元存储的数据位数越多，容量密度就越大。因为 5 大于 4 大于 3 大于 1，即 PLC
能在一个存储单元中存储的位数最多。所以，容量密度最大的介质是 B.PLC。

19、“线与”是指哪种类型门器件相与？
A.RS232
B.CMOS
C.LVTTL
D.OC/OD
答案：D
解析：首先，“线与”是指两个或多个输出端直接相连可以实现与逻辑功能的一种方式。

CMOS（ComplementaryMetalOxideSemiconductor，互补金属氧化物半导体）门器件本身
不支持“线与”。
LVTTL（LowVoltageTransistor-TransistorLogic，低电压晶体管-晶体管逻辑）门器件也不
支持“线与”。
综上所述，能够实现“线与”的门器件是 OC/OD，答案选择 D。
