L5 内核与进程

内核态/用户态 · 进程 vs 线程 · fork 与 COW · fork 循环题

1. 内核态与用户态

操作系统把 CPU 运行级别分成两类，以隔离用户程序和硬件：

  • 用户态：普通程序运行，只能访问自己的地址空间，不能直接操作硬件。
  • 内核态：操作系统运行，可以访问所有资源、控制硬件、切换进程。
  • 系统调用：用户态通过特定指令（如 svc/syscall）进入内核态，完成后再返回。

快速检查

用户态程序需要访问硬件时，通常通过什么进入内核态？

系统调用是用户态进入内核态的受控通道。

2. 进程 vs 线程

特性进程 Process线程 Thread
地址空间独立与同进程线程共享
资源拥有独立资源（打开文件、页表等）共享进程资源
调度单位是现代 OS 中线程是基本调度单位
切换开销大（页表、TLB 等）小（栈、寄存器）
崩溃影响不影响其他进程可能导致整个进程崩溃

快速检查

同一进程内的多个线程共享什么？

同一进程内的线程共享地址空间中的代码、数据、堆和打开的文件等。

3. fork 与写时复制 COW

fork() 创建当前进程的完整副本（子进程），但现代 OS 使用 写时复制（Copy-On-Write, COW）：

  • 刚 fork 时，父子共享同一物理页，页表标记为只读。
  • 任一进程尝试写入时，内核复制该页，再让写者修改私有副本。
  • 如果 fork 后直接 exec，原来地址空间会被替换，几乎不复制。
pid_t pid = fork();
if (pid == 0) {
    // 子进程
    execlp("ls", "ls", NULL);
} else if (pid > 0) {
    // 父进程
    wait(NULL);
}

快速检查

fork 后父子进程刚创建时，物理内存页的关系是？

这就是写时复制（COW），减少 fork 后立刻 exec 的开销。

4. fork 循环题

常见面试题：for (int i = 0; i < n; i++) fork(); 最终会产生多少个进程？

每次 fork() 调用都会让当前进程复制一份；两个进程继续循环。所以总进程数（含父进程）是 2^n。

for (int i = 0; i < 2; i++) {
    fork();
}
printf("hello\n");

上面会打印 4 次 hello，因为有 4 个进程。注意题目常问“打印多少次”而不是“创建多少子进程”。

快速检查

for (i = 0; i < 3; i++) fork(); 最终共有多少个进程？

n 次 fork 会产生 2^n 个进程，n=3 时 8 个。
