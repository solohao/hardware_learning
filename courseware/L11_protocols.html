1. TCP 可靠性机制

TCP 通过多种机制保证可靠传输：

  • 序列号与确认应答：发送端编号，接收端回复 ACK。
  • 超时重传：未收到 ACK 则重发。
  • 滑动窗口：提高吞吐量，允许连续发送多个包。
  • 流量控制：接收端通过窗口大小限制发送速率。
  • 拥塞控制：慢启动、拥塞避免、快重传/快恢复。

快速检查

TCP 用什么确认数据已成功到达对端？

TCP 接收方返回 ACK 确认收到数据，超时未 ACK 则重传。

2. OSI 七层模型

从下往上，每一层为上一层提供服务：

  1. 物理层：比特流、电气信号。
  2. 数据链路层：帧、MAC 地址、CRC。
  3. 网络层：IP、路由。
  4. 传输层：TCP/UDP、端口。
  5. 会话层：会话管理。
  6. 表示层：数据格式、加密、压缩。
  7. 应用层：HTTP、FTP、DNS。

快速检查

HTTP 位于 OSI 的哪一层？

HTTP、DNS、FTP 等都属于 OSI 第七层应用层。

3. 状态机 FSM

有限状态机由三部分组成：

  • 状态 State：系统当前所处模式。
  • 事件 Event：触发状态转换的输入。
  • 转移 Transition：事件+当前状态 → 新状态 + 动作。
typedef enum { IDLE, RUNNING, STOPPED } State;

State handle(State s, Event e) {
    switch (s) {
        case IDLE:
            if (e == START) return RUNNING;
            break;
        case RUNNING:
            if (e == STOP) return STOPPED;
            break;
        case STOPPED:
            if (e == RESET) return IDLE;
            break;
    }
    return s;
}

快速检查

有限状态机的三个基本要素是？

FSM = 状态集合 + 事件 + 状态转移函数/表。

4. 手写 strcmp

逐字符比较，直到遇到不同字符或 \0。

int my_strcmp(const char *a, const char *b) {
    while (*a && *a == *b) {
        a++;
        b++;
    }
    return (unsigned char)*a - (unsigned char)*b;
}
  • 返回 0：相等。
  • 返回正数：a > b。
  • 返回负数：a < b。
  • 强制转 unsigned char，避免 char 为有符号时减法溢出。

快速检查

my_strcmp("abc", "abd") 的返回值是多少？

'c'(99) 小于 'd'(100)，所以 a-b 为负。

5. 手写栈

栈是后进先出（LIFO）结构，可用数组或链表实现。

#define MAX 100
int stack[MAX];
int top = -1;

void push(int v) {
    if (top >= MAX - 1) return;  // 满
    stack[++top] = v;
}

int pop() {
    if (top < 0) return -1;      // 空
    return stack[top--];
}

int empty() { return top == -1; }

快速检查

栈的核心特性是？

栈是 LIFO：最后进入的最先弹出。
