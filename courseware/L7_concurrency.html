1. 三种锁：互斥量、信号量、自旋锁

锁特点适用场景
mutex二值锁，获取不到则阻塞睡眠进程/线程临界区，可能长时间持有
semaphore计数锁，可多个持有者资源池、生产者消费者
spinlock获取不到则忙等（轮询）中断上下文、SMP 极短临界区

自旋锁不会睡眠，所以适合中断上下文；但长时间自旋会浪费 CPU。

快速检查

在中断上下文里保护共享变量，通常用什么锁？

自旋锁不会睡眠，适合中断上下文短临界区。

2. 中断上下文不能睡眠

ISR 执行时没有对应的进程控制块（PCB），调度器无法把它挂起再调度其他任务。因此：

  • 不能调用可能阻塞的函数：如 sleep、printf、malloc、mutex_lock。
  • 临界区要尽可能短：只做读状态、清标志、唤醒底半部。
  • 复杂处理放到底半部（softirq、tasklet、workqueue）或主循环。

快速检查

中断服务程序里为什么不能调用 sleep？

中断上下文不属于任何进程，无法被调度器挂起，睡眠会导致系统卡住。

3. 原子操作

原子操作是不可分割的：执行过程中不会被其他 CPU 或中断打断，常用于计数器和标志位。

atomic_t cnt = ATOMIC_INIT(0);
atomic_inc(&cnt);   // 计数 +1，无需加锁

// CAS：比较并交换
bool cas(int *p, int expected, int newval) {
    if (*p == expected) { *p = newval; return true; }
    return false;
}

对于 32 位变量的一次读写，在大多数架构上是原子的；但对多字操作或读-改-写仍需显式原子 API。

快速检查

原子操作的主要意义是什么？

原子操作在执行期间不可分割，避免竞态。

4. SMP 与缓存一致性

SMP（Symmetric Multi-Processing）：多个 CPU 核心共享内存，操作系统把它们视为对等的处理单元。

  • 每个核心有独立缓存，同一块内存可能在多个缓存中存在副本。
  • 缓存一致性协议（如 MESI）保证各缓存副本一致。
  • 多核访问共享变量需要锁、原子操作或内存屏障，防止乱序和脏数据。

快速检查

SMP 系统中，多核共享内存时最需要解决的问题是？

多核共享内存必须保证各核心缓存一致，并正确同步并发访问。
