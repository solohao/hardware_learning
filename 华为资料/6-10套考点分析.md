# 华为2024届校园招聘·硬件开发工程师 第6-10套考点分析

> 题目来源：硬件通用/单板开发  
> 题型：单选题、多选题、判断题  
> 说明：第6套已去除重复题，第9-10套部分题目与第8套相同（已标注）

---

## 一、整体考点方向概述

第6-10套题目考点范围相比第1-5套**显著扩展**，新增了以下方向：
- **计算机组成原理**（8086CPU、存储器、总线、寄存器）
- **数字信号与编码**（二进制补码、BCD码、进制转换、波特率/比特率）
- **网络与通信协议**（OSI模型、以太网、IP地址、DMA）
- **模拟信号处理**（滤波器、运算电路、谐振电路、LTI系统）
- **材料与制造工艺**（焊接润湿性、疲劳破坏、齿轮、退火）
- **射频与光通信**（激光特性、光纤、波导、Y因子）

高频考点仍聚焦在：**SRAM/DRAM、滤波器、逻辑门电路、示波器测量、编码与进制转换**。

### 📌 5. 存储器与计算机体系结构

| 考点细项 | 涉及套数 | 具体题目关键词 |
|---------|---------|--------------|
| SRAM vs DRAM | 7、8、9套 | DRAM用电容存储→需定时刷新；SRAM用触发器→无需刷新；DRAM集成度高；SRAM速度快用于Cache |
| Flash存储特性 | 8、9、10套 | Flash上电后维持原存储信息（非全0也非全1）；掉电不丢失 |
| 存储器刷新需求 | 10套 | **不需要**刷新的存储器：SRAM、EEPROM、NAND Flash；DDR**需要**刷新 |
| Cache写策略 | 8套 | Write back：只写Cache不立即写Memory，性能高但结构复杂；Write through：同时写Memory，简单但低效 |
| 哈佛/冯诺依曼结构 | 10套 | 哈佛：程序/数据存储分开；冯诺依曼：程序/数据存储合并（题目描述**相反**，故错误） |
| 半导体存储器工艺 | 7套 | 双极型：速度快，功耗大；MOS型：集成度高，功耗小 |
| I/O设备编址方式 | 7套 | 统一编址（存储器映射I/O）与独立编址 |
| I/O适配器 | 9套 | I/O设备必须通过适配器（接口）才能接到系统总线 |
| DMA传输 | 8、9套 | 需DMA控制器；速度快降低CPU负载；传输**前后**需CPU参与（初始化和结束）；总线在CPU和DMA控制器间复用 |
| PCI总线 | 8套 | PCI总线宽度为**32/64位**（非16位）；地址线与数据线复用；支持即插即用 |
| SPI总线 | 10套 | 支持全双工；支持多设备（通过片选CS区分）；4根信号线（SCLK/MOSI/MISO/CS）；**不是**只支持点对点 |
| 串行通信格式计算 | 7套 | 1起始+7数据+1校验+1停止=10位/字符；2400bps → 最大240字符/秒 |
| 波特率计算 | 10套 | 通信速率=基准时钟/(波特率因子×除数)；9600=1.8432M/(16×除数)→除数=12 |
| RS-232校验方式 | 8套 | RS-232采用**奇偶校验** |
| RS-232逻辑电平判断 | 6、7套 | RS-232-C电气特性：低电平（+3+15V）表示**逻辑0**（正确）；RS-232属于**双工**通信 |
| RS-232电平 | 7、8套 | 逻辑0对应+3V~+15V；逻辑1对应-3V~-15V（RS-232 C，低电平=逻辑0正确） |
| 奇偶校验能力 | 9套 | 奇偶校验只能检测**奇数个**比特错误，**不能**发现偶数个（如2个）比特错误 |
| IP地址 | 7套 | 192.168.0.1是**C类**私有地址（正确） |
| 二进制补码 | 7、8套 | 正数原码=反码=补码；负数补码=原码取反+1；+1补码：0000_0001；-1补码：1111_1111 |
| 进制转换 | 6、7套 | 八进制765转二进制：7=111, 6=110, 5=101 → 111110101；8位补码11000110→真值=-58 |
| BCD码 | 9套 | 8421码：1001 0111 → 9×10+7 = 97 |
| 模拟信号数字化 | 8套 | 过程顺序：**采样→量化→编码** |
| ADC精度计算 | 10套 | 8位ADC，参考2.5V，检测1V：分辨率=2.5/256≈0.0098V≈0.01V |

|---------|---------|--------------|

| 谐振电路Q值 | 10套 | Q越大→选择性越好、通频带越**窄**、曲线越尖锐 |

## 五、易错考点提示（第6-10套）

| 易错点 | 正确结论 |
|-------|---------|
| 铝电解电容ESR随温度升高而增大 | ❌ 温度**升高**→ESR**减小**；温度降低→ESR增大 |
| 引脚Cu/Ni/Au镀层最终是Au与焊料形成焊接 | ❌ Au溶入焊料，最终是**Ni**与焊料形成焊接 |
| ARM属于CISC架构 | ❌ ARM属于**RISC**架构 |
| 哈佛结构将程序和数据存储合并 | ❌ 哈佛结构**分开**存储；冯诺依曼结构**合并**存储（题目常把二者描述对调） |
| 三孔插座接地是设备工作的必要条件 | ❌ 接地是安全保护，不接地设备仍可工作 |
| 程序计数器保存正在执行的指令地址 | ❌ PC保存**下一条将要执行**的指令地址 |
| 小齿轮齿根厚度比大齿轮小 | ❌ 相啮合标准齿轮中，**小齿轮齿根厚度更大** |
| BUCK电路中用电解电容代替陶瓷电容可减小纹波 | ❌ 电解电容ESR更大，反而增大纹波，**不能**用于减小纹波 |
| 奇偶校验可以发现两个比特的数据错误 | ❌ 奇偶校验只能发现**奇数个**比特错误，**不能**检测偶数个错误 |
| 测差分信号可用单端无源探头 | ❌ 测差分信号需使用**差分探头** |
| LC并联谐振阻抗为零 | ❌ LC**并联**谐振阻抗为**无穷大**；LC**串联**谐振阻抗为零 |
| 示波器带宽是信号衰减到-6dB的频率 | ❌ 带宽定义为衰减到**-3dB（70.7%）**时的频率 |
| 1mV = 30dBuV | ❌ 1mV = 0dBmV = **60dBuV**（dBuV = 20log(1000μV/1μV) = 60dB） |
