L6 进程状态与虚存

僵尸/孤儿/守护 · 虚拟内存与 MMU · 缺页与 mmap · RAM/ROM/FLASH

1. 进程状态：僵尸、孤儿、守护

  • 僵尸进程 Zombie：子进程已结束，但父进程尚未调用 wait()/waitpid() 回收。内核保留少量信息供父进程查询。
  • 孤儿进程 Orphan：父进程先于子进程退出，子进程被 init/systemd 接管，最终由 init 回收。
  • 守护进程 Daemon：后台运行、与终端脱离、通常启动时由系统管理，如网络服务。
// 避免僵尸：父进程及时 wait
pid_t pid = fork();
if (pid == 0) { exit(0); }
else { wait(NULL); }

快速检查

父进程未回收已结束子进程，子进程变成什么？

已结束但父进程未 wait 的子进程称为僵尸进程。

2. 虚拟内存与 MMU

每个进程看到的地址都是“虚拟地址”，由 内存管理单元（MMU） 配合页表映射到物理地址。

  • 隔离：进程 A 不能直接访问进程 B 的内存。
  • 超额分配：进程可申请比物理内存更大的虚拟空间，按需装入物理页。
  • TLB：页表的高速缓存，加速地址转换。

快速检查

把虚拟地址转换成物理地址的硬件单元是？

MMU 负责虚拟地址到物理地址的转换。

3. 缺页中断与 mmap

  • 缺页异常 Page Fault：访问的虚拟页当前不在物理内存或未映射，CPU 陷入内核，OS 负责加载页面或处理错误。
  • 按需分页：程序启动时并不全部加载，用到哪页再调哪页。
  • mmap：把文件或设备映射到进程虚拟地址空间，可像访问内存一样读写文件。
// 映射文件到内存
void *addr = mmap(NULL, length, PROT_READ, MAP_PRIVATE, fd, 0);

快速检查

访问一个已分配但尚未载入物理内存的虚拟页，会触发什么？

缺页异常会触发 OS 的页调入或错误处理流程。

4. RAM / ROM / FLASH

存储器特点典型用途
RAM读写快，掉电丢失运行时变量、堆、栈、缓冲区
ROM只读，出厂烧录，不可改启动 BootROM、固定程序
FLASH非易失，按块擦除，有擦写次数固件、配置、文件系统

嵌入式启动流程通常是：CPU 从 ROM/FLASH 加载 Bootloader → 初始化 RAM → 把 OS/APP 从 FLASH 复制到 RAM 运行。

快速检查

嵌入式设备中，固件通常存储在哪里？

FLASH 可擦写且非易失，是存放固件最常用的介质。
