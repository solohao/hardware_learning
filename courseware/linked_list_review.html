一、链表是什么

链表由若干 节点（Node） 组成，每个节点保存两部分：

  • val：数据
  • next：指向下一个节点的指针

最后一个节点的 next = NULL，表示链表结束。

形象化

C 语言节点定义

struct ListNode {
    int val;
    struct ListNode *next;
};

// 创建节点
struct ListNode* create_node(int x) {
    struct ListNode *node = malloc(sizeof(struct ListNode));
    node->val = x;
    node->next = NULL;
    return node;
}

二、遍历链表

链表不能像数组一样用下标随机访问，只能从头开始一个一个走。

void print_list(struct ListNode *head) {
    struct ListNode *p = head;
    while (p != NULL) {
        printf("%d ", p->val);
        p = p->next;   // 移动到下一个节点
    }
}
永远不要再使用 p 前移之后才访问它原来的位置，除非你先保存了。

三、插入与删除

头插法

新节点插到最前面，适合“逆序建表”。

void push_front(struct ListNode **head, int x) {
    struct ListNode *node = create_node(x);
    node->next = *head;   // 新节点指向旧头
    *head = node;         // 更新头指针
}

删除节点

删除当前节点时，需要知道它的 前一个节点，然后让前节点跨过当前节点。

// prev->next 就是要删除的节点
void delete_node(struct ListNode **head, struct ListNode *target) {
    if (*head == target) {
        *head = target->next;
        free(target);
        return;
    }

    struct ListNode *prev = *head;
    while (prev->next != target) {
        prev = prev->next;
    }
    prev->next = target->next;
    free(target);
}

四、虚拟头节点（dummy）

很多链表题需要对头节点做删除或插入操作。如果直接对头节点操作，要单独判断很多边界情况。dummy 节点可以让我们把“头节点”当成普通节点处理。

struct ListNode* removeElements(struct ListNode* head, int val) {
    struct ListNode dummy;
    dummy.next = head;

    struct ListNode *p = &dummy;
    while (p->next) {
        if (p->next->val == val) {
            p->next = p->next->next;  // 跳过目标节点
        } else {
            p = p->next;
        }
    }

    return dummy.next;
}
dummy 节点本身不保存数据，只作为统一入口。返回时记得 return dummy.next。

五、双指针 / 快慢指针

双指针是链表题最常见的技巧：

  • 快慢指针：一个走两步，一个走一步，用于判环、找中点。
  • 前后指针：一个先走 n 步，再同步走，用于删除倒数第 n 个节点。

判断是否有环

int hasCycle(struct ListNode *head) {
    struct ListNode *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return 1;
    }
    return 0;
}

找中点

struct ListNode* middleNode(struct ListNode *head) {
    struct ListNode *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow;
}

六、反转链表

把每个节点的 next 指向前一个节点。需要三个指针：前一个、当前、下一个。

struct ListNode* reverseList(struct ListNode* head) {
    struct ListNode *prev = NULL;
    struct ListNode *cur = head;
    while (cur) {
        struct ListNode *next = cur->next;
        cur->next = prev;   // 当前节点掉头指向 prev
        prev = cur;         // prev 前移
        cur = next;         // cur 前移
    }
    return prev;  // 新的头节点
}

七、合并两个有序链表

用 dummy 节点作为新链表头，然后逐个比较两个链表当前节点的大小。

struct ListNode* mergeTwoLists(struct ListNode* l1, struct ListNode* l2) {
    struct ListNode dummy;
    struct ListNode *p = &dummy;
    dummy.next = NULL;

    while (l1 && l2) {
        if (l1->val <= l2->val) {
            p->next = l1;
            l1 = l1->next;
        } else {
            p->next = l2;
            l2 = l2->next;
        }
        p = p->next;
    }

    if (l1) p->next = l1;
    if (l2) p->next = l2;

    return dummy.next;
}
