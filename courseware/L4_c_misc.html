1. sizeof 与 strlen

  • sizeof 是编译时运算符，返回类型或对象占用的字节数。
  • strlen 是运行时函数，返回字符串中 \0 之前的字符个数。
char s[] = "abc";
printf("%zu\n", sizeof(s));  // 4（包含结尾 \0）
printf("%zu\n", strlen(s));  // 3（不包含 \0）

char *p = "abc";
printf("%zu\n", sizeof(p));  // 4/8，指针大小

快速检查

char s[] = "abc"; 中，哪个结果包含字符串结尾的 \0？

sizeof 计算数组总大小，包含 \0；strlen 只计算 \0 前字符数。

2. 函数指针与回调

函数指针保存函数的入口地址，可用于回调、策略模式、把函数作为参数传递。

int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }

int (*op)(int, int);       // 声明函数指针
op = add;
printf("%d\n", op(2, 3));  // 5

// 回调
int calc(int a, int b, int (*f)(int, int)) {
    return f(a, b);
}
printf("%d\n", calc(2, 3, sub));

快速检查

下面哪个声明是“指向函数的指针”？

括号让 * 先与 pf 结合，表示 pf 是指向函数的指针。

3. 内联函数 inline

inline 是对编译器的建议：把函数体直接展开到调用处，减少函数调用开销。

  • 是否真正内联由编译器根据优化级别和函数大小决定。
  • 内联函数有类型检查，比宏更安全；但滥用会增加代码体积。
  • 在嵌入式中，小型频繁调用的函数适合内联。
static inline int max(int a, int b) {
    return a > b ? a : b;
}

快速检查

inline 关键字的主要作用是？

inline 是建议，编译器会权衡是否真正内联展开。

4. 中断函数（ISR）

中断服务程序（Interrupt Service Routine）响应硬件事件，要求短小、快速、不能阻塞。

  • 不能睡眠/阻塞：中断上下文没有进程上下文，调度器无法调度它。
  • 避免 printf/malloc：这些函数可能加锁，导致中断里死锁或重入问题。
  • 操作共享变量要加保护：对 8/16/32 位非原子变量，用关中断或自旋锁保护。
  • 典型做法：ISR 设置 volatile 标志，主循环轮询处理。
volatile int flag = 0;

void ISR_handler(void) {
    flag = 1;  // 简短操作
}

int main() {
    while (1) {
        if (flag) {
            flag = 0;
            do_work();
        }
    }
}

快速检查

中断服务程序里一般不应该做以下哪件事？

printf 可能持锁和阻塞，在中断里调用容易导致死锁或崩溃。
