1. 内存三题一张图

面试口述内存时，先画出地址空间图，然后能讲清楚：

  1. 栈和堆的区别（自动分配 vs 动态分配，生命周期，大小）。
  2. malloc/free 流程，野指针怎么产生（free 后置 NULL）。
  3. struct 对齐与 padding，位域和 union 的使用场景。

2. 进程 / 线程 / 锁

口述这三块时，可以按这个结构组织：

  • 进程：独立地址空间，fork 创建，COW，exec 替换镜像。
  • 线程：共享地址空间，轻量，切换快，注意同步与竞态。
  • 锁：mutex（阻塞）、semaphore（计数）、spinlock（忙等，中断用）。
// 中断 + 主循环共享标志
volatile int irq_flag = 0;

void ISR() { irq_flag = 1; }

int main() {
    while (1) {
        if (irq_flag) { irq_flag = 0; handle(); }
    }
}

快速检查

中断上下文和主循环共享标志变量，应声明为？

volatile 防止编译器优化，确保每次读写都访问内存。

3. 口述答题技巧

  • STAR 化：先说概念，再举例子，最后讲陷阱。
  • 画图：地址空间、fork 树、锁流程、TCP 握手、OSI 分层。
  • 讲出为什么：不要只背答案，解释“为什么这样设计”。
  • 结合项目：尽量提到自己在 STM32/Linux 上遇到的实际场景。

快速检查

结构化回答 + 画图 + 结合实际，最能体现理解深度。
